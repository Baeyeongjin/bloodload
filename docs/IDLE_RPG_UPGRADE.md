# 사냥·공략·수집 흐름 개선 — 2026-09-09

사용자는 게임을 더 재미있게 만들고 싶다고 요청했고, 전투·빌드와 성장·파밍을 균형 있게 개선하는 방향을 선택했다. 기존 콘텐츠와 보상을 연결하는 데 집중했다.

- **추천 편성:** 성장의 스킬 화면과 사냥 게시판에서 `추천 편성 · 프리셋`을 연다. 보유 스킬의 레벨·재사용 시간·실제 대상 규칙·가호·조합을 고려한 무리 사냥/보스 공략 두 편성을 미리 보고 장착한다. 추천은 3대상/1대상을 가정하는 휴리스틱이며 정확한 DPS나 승리를 보장하지 않는다. 적용 시 자동 장착이 꺼지고 기존 쿨다운·저장 프리셋·장비·재화는 유지한다.
- **재도전과 다음 보상:** 본편 보스·중간보스의 사망/시간 초과 시점에 남은 체력을 기록한다. 사냥 게시판에서 직전 도전과 비교하고 편성/성장 화면으로 이동할 수 있다. 자동 재도전은 계속된다. 다음 미격파 보스의 기존 첫 보상도 같은 게시판에 예고한다. 기록은 현재 세션의 같은 구간에만 적용한다.
- **가이드 이동:** 진행 중인 가이드를 누르면 성장·소환·도감·사냥 중 해당 화면으로 이동한다. 완료한 가이드는 기존처럼 한 번에 한 보상씩 수령한다.
- **소환 결과:** 신규 수집과 중복 조각의 증가·진행·조합 가능 여부를 카드에 표시한다. 한 번의 다중 소환 안에서도 각 수령 시점의 결과를 보존한다. 표시용 receipt는 저장 장비에 넣지 않는다.
- **강화 결정:** 다음 레벨의 장착·보유 효과와 실제 강화 재료를 표시하고, 만렙/재료 부족 버튼을 공통 판정으로 비활성화한다. 새 게임에서 저장 프리셋 슬롯이 비어 있던 초기화도 수정했다.

전투 수치·소환 확률·보상량·저장 형식·이미지는 이번 작업에서 변경하지 않았다. 이전에 완성한 LibreSprite 보스 VFX는 그대로 사용한다. 검증은 `SkillRecommendationCheck`, `GrowthFeedbackCheck`, `FunLoopCheck`와 기존 `PresetCheck`, `GoalTest`, `SkillTest`, `BossPatternCheck`를 사용한다. 모든 자동 게임 실행은 두 Windows 앱 데이터 경로를 같은 새 QA 프로필로 격리한다.

# 방치형 성장 편의 개선 — 2026-09-08

사용자가 전체 업그레이드를 승인한 뒤 아래 두 개선을 구현했다.
`tests/IdleGrowthCheck.gd`는 exit 0이며 실제 Godot 렌더 화면 3장도 검토했다.

## 이미 있는 기능

- 오프라인 진행: `_grant_offline`이 생존·처치 시간을 계산해 단계를 진행하고 혈액을 방치
  상자에 적립한다. 기본 8시간, 성장 보너스 포함 최대 16시간이다.
- 수령: `_claim_chest`가 공용 보상 팝업에 경과 분·혈액·경험치·혈정을 보여 준다.
- 성장: 스탯 x1/x10/x100/MAX, 스킬 일괄 레벨업, 장비·스킬 일괄 조합이 있다.
- 다음 목표: `GoalDefs`의 상시 가이드 1개와 탭별 실행 가능 알림 점이 있다.
- 반복 수령: 일일·주간 임무, 업적, 패스, 계약의 서에 일괄 수령이 있다.

새 재화나 추가 일괄 처리 시스템보다 아래 두 흐름의 정확도와 안내를 개선한다.

## 방치 상자에 당시 획득 내역 고정

기존에는 상자에 `gold`와 `minutes`만 저장해, 접속 후 강화·기록 갱신을 하고 수령하면
경험치와 표시 혈정이 현재 stage/DPS/소탕 시급으로 다시 계산됐다.

- 적립 시 경험치와 표시용 혈정을 함께 누적하고 저장한다. 혈정의 기존 즉시 지급은 유지한다.
- 수령 팝업은 저장된 값만 표시·지급하고 모든 상자 항목을 함께 비운다.
- 기존 상자만 있는 구세이브는 로드 시 한 번 현재 기준으로 이관한다. 과거 실제 값은 복원할 수 없다.
- 같은 상자를 쓰는 상점 `warp`와 `--chest` 검수 경로도 같은 적립 규칙을 사용한다.
- 방치 팝업 하단을 32px 늘리고 그 안에 진행 구간 수·이번 수령으로 오른 영웅 레벨을
  표시한다. 실제 촬영에서 발견한 뒤쪽 강화 행과의 글자 겹침을 해결했다.
- 혈정에는 `지급됨`을 표시해 이번 클릭에서 다시 지급하는 것으로 오해하지 않게 한다.

구현 위치: `Main.gd`의 chest 변수, `_grant_offline`, `_claim_chest`, `_shop_buy`의 warp 분기,
`_save_game_inner`, `_load_game`, `--chest` 처리. 기존 보상창을 재사용한다.

검사 통과: 적립 후 DPS·stage·미궁 기록 변경에도 값 불변; 메모리 ConfigFile 직렬화/복원
합계 보존; 혈정 이중 지급 없음; 반복 수령 불변; 구세이브 이관·명시적인 0 보존;
실제 warp 구매와 2시간 복귀 적립; 5초 앱 전환 미지급.

## MAX 강화의 0레벨 구매 차단과 구매량 안내

기존 MAX 모드는 혈액이 1레벨 값에도 못 미칠 때 비용 0인 버튼과 성장 알림 점을 켜고,
레벨 변화 없이 훈련 임무 횟수를 올렸다.

- `_buy`에서 n≤0을 차단한다. UI와 알림 점도 실제 구매 단계 수가 양수일 때만 활성화한다.
- MAX 구매 불가 시 `혈액 부족`과 1레벨의 실제 가격을 표시한다. 구매 버튼은 `+N레벨`과
  비용 두 줄이며, 툴팁에서 필요 혈액·부족액을 확인할 수 있다.
- 선택한 x10/x100의 비용·상한 제한은 유지한다. 만렙보다 높은 옛 상태도 음수 수량이 되지 않는다.

구현 위치: `_refresh_growth`, `_growth_mode_todo`의 stat 분기, `_step_for`, `_buy`.
검사 통과: MAX n=0이면 지갑·레벨·일일/주간 훈련 불변; 실제 구매 수량/가격 일치;
상한 직전 x100은 남은 2단계만 구매; 초과 레벨에서 음수 수량 없음. 실제 프로젝트 폰트,
아이콘·스타일 여백으로 버튼 글자 폭과 두 줄 최소 높이 ≤48px을 확인했다.

Windows certificate store 경고 외 스크립트 오류는 없었다.
