# M1 보스·자동 스킬 완료 (2026-08-03)

> 작업일: 2026-08-03

- 5단계 중간보스: 한 마리, HP ×3.5, 크기 ×1.3, 막별 이름 접두어와 등장 흔들림
- 10단계 보스: `boss_1~5_walk` 연결, 60초 제한과 같은 단계 재도전
- 보스 전용 attack이 생기기 전까지 원본 몹 attack을 임시 사용
- 자동 스킬 우선순위: 흡혈 강타(8초) → 피의 파도(14초) → 망령 소환(20초)
- 흡혈 강타는 실제 피해 20%를 피로 회수
- 피의 파도는 현재 전열 전체 타격
- 망령 소환은 6초간 초당 피해 +30%
- 스킬 모션은 기존 `heavy`/`cast`, 이펙트는 기존 애니메이션 재사용
- 오프라인 중간보스 판정에도 한 마리/HP ×3.5를 동일 적용

검증:

- `BalanceTest OK`
- `GearTest OK`
- `CombatRulesTest OK`
- 메인 씬 600프레임 오류 없음
- 576×896 자동 캡처 레이아웃 정상
