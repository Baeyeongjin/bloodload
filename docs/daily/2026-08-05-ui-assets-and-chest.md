### widget_bar 를 잘라 쓴 이유

원본 160px 가운데(x 60~74)에 **리벳 기둥**이 있다. 9-slice 는 가운데를 늘리므로
무늬가 있는 기둥이 그 안에 있으면 늘어나 뭉개진다. 찢어진 왼쪽(0~60)과 오른쪽
기둥(140~160)만 남겨 80×44 로 잘랐다. 가죽 무늬는 균일해서 가로로 많이 늘려도 산다.

## 방치 보상 상자

**예전**: 접속하면 피가 지갑에 바로 들어가고 배너만 6초 떴다 — 받은 느낌이 없다.
**지금**: 계산은 접속할 때 하되 `chest_gold` 에 담아 두고, 눌러야 지갑에 들어간다.

- 자리는 **전투 띠 위쪽 하늘**. 처음엔 레퍼런스처럼 화면 가운데 아래에 뒀는데
  거기는 지면이라 몹 몸통과 겹쳤다(렌더로 확인). 그 다음 `VIEW_TOP+26` 은 HP 라벨과
  겹쳐서 `VIEW_TOP+44` 로 내렸다.
- `round_btn` 을 뒤에 깔았다. 상자만 있으면 배경 소품처럼 보이고 누를 것으로 안 읽힌다.
- 저장: `chest.gold` / `chest.minutes`. 옛 저장본은 0 으로 시작한다.
- 단계 전진 알림은 그대로 배너로 둔다(상자와 별개 정보다).

개발 플래그 `--chest` 추가.

## 상단 HUD 재배치 (레퍼런스 대조 후)

사장님 지적("ui 배치 이상해"). 레퍼런스와 우리 배치를 **비율로 실측해 대조**한 결과,
근본 차이는 **레퍼런스는 요소를 네 모서리로 흩는데 우리는 가로 띠를 층층이 쌓는다**는 것.

| | 레퍼런스 | 고치기 전 우리 |
|---|---|---|
| 재화 | 우측 상단 압축(폭의 52%) | **전체 폭 3칸(100%)** |
| 좌측 상단 | 초상화 + 레벨 + 순위 | `레벨 1` 글자만 — **비어 있음** |
| 스테이지명·진행바 | 가운데 **한 덩어리** | 이름은 2줄째, 바는 전투 화면 위 — **쪼개짐** |
| 진행바 | 가운데 짧게, 장식 있음 | 전투 최상단 전체 폭 7px 실선 |
| 상자 | 하단 가운데 | 우측 상단 |

고친 뒤:

```
왼쪽 위  : 초상화 + 레벨      (누구인가)
오른쪽 위: 재화 알약 (2행)     (얼마 있나)
가운데 위: 막이름 -> 단계·처치·시간 -> 진행바 한 덩어리
오른쪽   : 전투력
하단 왼쪽: 보물상자 / 하단 오른쪽: 가이드 카드
```

### 폰트 실측이 잡은 것 두 개

1. `혈액 999.9t` 108px > 알약 안쪽 96px — **이름을 뺐다.** 아이콘이 바로 왼쪽에
   있어서 이름은 중복이고, 레퍼런스도 아이콘 + 숫자만 쓴다.
2. `깨어난 무덤  100-10` 336px > 가운데 칸 306px — **단계 번호를 진행 줄로 내렸다.**

둘 다 `clip_text` 라 화면에서는 조용히 잘렸을 것들이다. `GearTest` 에 칸 5개를 추가했다.

### 우측 세로 버튼은 여전히 안 만들었다

넣어 보니 도감/소환/장비인데 하단 탭바와 똑같은 복사본이라 지웠다. 레퍼런스의 그
자리는 하단 내비에 **없는** 콘텐츠(이벤트/우편/길드)용이다 — 기능이 생기면 그때 단다.

**여백은 전부 실측이다** — 안쪽 평평한 면(어두운 곳)이 시작되는 열/행을 읽었다.

### 진행바가 두 종류인 이유

- `bar_slim`(상단): 좌우 **화살촉 캡**이 native 로 남고 홈통만 늘어난다. 숫자는
  홈통 안에만 넣는다 — 바 전체 폭을 주면 화살촉 위까지 뻗어 잘린다.
- `bar_mini`(가이드 카드): 캡이 없는 단순 홈통. 카드 안에서는 장식이 오히려 방해다.

둘 다 **채움을 틀 밑에 깐다.** 위에 그리면 금테와 캡을 덮는다.
