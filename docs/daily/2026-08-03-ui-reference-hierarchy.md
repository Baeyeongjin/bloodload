# UI 레퍼런스 기반 계층 정리

> 작업일: 2026-08-03

## 확정한 방향

- 사용자가 제공한 수집형 RPG 장비함·하단 메뉴 레퍼런스를 다음 UI 작업의 기본 기준으로 삼는다.
- 화려한 반복 장식보다 영역 분리, 고정된 칸, 짧은 행동 문구를 우선한다.
- 콘텐츠 패널과 하단 탭바를 한 장으로 덮지 않는다.
- 상세 팝업은 전체 화면을 검게 차광하지 않고 뒤 화면의 맥락을 남긴다.
- 장비 등급은 보관함·상세에서 배경과 테두리색으로 구분한다.
- 움직이는 반짝임은 보상을 공개하는 소환 결과의 희귀 이상에만 사용한다.

상세 규칙은 `docs/UI_RULES.md`의 **레퍼런스 기반 시각 계층** 절에 고정했다.

## 적용

- 콘텐츠: `y=480~800`, 하단 탭바: `y=800~896`의 독립 9-slice 패널
- 하단 탭: 4등분, 48px 아이콘, `성장/장비/소환/도감` 이름표
- 소환 결과 반짝임: 희귀 1개, 영웅 2개, 전설 4개
- 보관함·상세: 반짝임 없음
- 상세 팝업 전체 차광: 투명

## PixelLab 판단

하단 탭바 전용 자산을 세 번 시험했지만 반복 난간 또는 잘못된 탭 개수로 생성되어 폐기했다.
기존 `panel.png` 9-slice를 별도 판으로 재사용한 결과가 레퍼런스에 가장 가까워 이를 채택했다.

## 검증

- `576×896` 보관함에서 콘텐츠와 탭바의 이중 경계 확인
- 상세 팝업 뒤 보관함과 전투 화면이 보이는 것 확인
- 10연 결과에서 희귀·영웅만 반짝이고 보관함·상세에서는 반짝이지 않는 것 확인
