# 2026-08-03 UI 테두리·소환 반짝임 정리

## 사용자 피드백

- 공용 창 모서리와 테두리가 반복되어 어색함
- 하단 UI가 콘텐츠와 분리되지 않고 폭이 남거나 깨져 보임
- 소환 결과의 희귀 이상 효과가 영상처럼 반짝이지 않고 정지 장식처럼 보임

## 적용

- PixelLab `create_image_pixen`으로 반복 장식 없는 공용 패널 생성
  - `assets/ui/panel_clean.png`
  - Job: `3f8a8aac-0ae5-4663-b025-f2bda2fd7d92`
- PixelLab에서 하단 메뉴 단일 셀 생성 후 2배 크기로 4회 반복
  - `assets/ui/tab_cell.png`
  - Job: `34d819fa-6215-4e62-80bf-f8a8c5342c5c`
- 8칸으로 잘못 생성된 전체 탭바 시안은 적용하지 않음
  - Job: `7f81814d-2ec5-4d2f-b549-f025b27823aa`
- `Ui.panel()`의 공용 원화를 교체하고 어두운 톤으로 보정
- 소환 카드를 먼저 SceneTree에 추가한 뒤 희귀도 효과를 생성하도록 순서 수정
- 반짝임을 알파·크기 Tween으로 반복해 나타남/확대/사라짐이 보이게 조정

## 확인

- Godot 576×896 실제 렌더: 성장, 장비 보관함, 소환 결과 여러 시점 확인
- 희귀 반짝임이 꺼진 시점과 켜진 시점이 서로 다름을 확인
- 하단 4칸이 각 144px로 화면 576px을 빈틈 없이 채움
- `BalanceTest.gd`, `CombatRulesTest.gd`, `GearTest.gd` 통과
- Windows 루트 인증서 경고는 기존 Godot 환경 경고이며 테스트 결과와 무관
