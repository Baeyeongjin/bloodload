# M3 장비 소환 연출과 보관함

> 작업일: 2026-08-03

## 완료

- 1회 소환은 중앙 대형 카드, 10연은 5×2 카드로 결과를 보여 준다.
- 결과 카드는 등급색으로 빛나며 순서대로 확대·페이드 인한다.
- 소환 장비는 자동 분해하거나 교체하지 않고 전부 `gear_inventory`에 저장한다.
- 같은 아이콘 중복은 해당 장비 조각으로 바뀌고, 더 높은 등급은 보관본을 갱신한다.
- 장비 탭을 `장착 장비 / 보관함`으로 나눴다.
- 보관함 5열 격자에 등급 틀, 아이콘, 레벨, 조각 수, 장착 상태를 표시한다.
- 보관함 카드를 누르면 무기·방어구·장신구의 해당 슬롯에 수동 장착한다.
- 기존 저장은 현재 장착 장비를 보관함에 한 번 복사해 마이그레이션한다.

## 자산 결정

기존 장비 아이콘, 등급 슬롯, 패널, 버튼만으로 예시 화면의 핵심 구조를 만들 수 있어
이번 작업에서는 PixelLab 신규 생성을 요청하지 않았다. 전용 소환 제단이나 별도 카드
프레임이 필요해지는 시점에만 PixelLab 자산을 추가한다.

## 검증

- 10연 결과 10개 보관, 결과 오버레이 표시, 수동 장착 자동 검사 통과
- 기존 밸런스·장비·전투 테스트 통과
- 메인 씬 600프레임 오류 없음
- 실제 10연 결과창과 보관함 5열 화면에서 겹침 없음

개발 캡처 플래그: `--pull=gear:10`, `--gear-mode=inventory`.
