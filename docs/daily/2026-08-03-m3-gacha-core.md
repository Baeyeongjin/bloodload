# M3 공용 뽑기 코어

> 작업일: 2026-08-03

## 완료

- 장비와 스킬이 함께 사용하는 `GachaDefs.gd`를 추가했다.
- 공개 확률은 일반 50%, 고급 30%, 희귀 14%, 영웅 5%, 전설 1%다.
- 10연은 희귀 이상 1개를 보장하고, 장비/스킬 각각 100연 전설 천장을 센다.
- 1회는 보석 30, 10연은 보석 300이며 하루 무료 1회는 두 종류가 공유한다.
- 첫 보스 최초 돌파마다 다음 1회분인 보석 30을 지급한다.
- 중복은 대상별 조각, 모든 뽑기는 공용 마일리지 1을 남긴다.
- 새 소환 탭에서 보석·마일리지·조각·천장·공개 확률·자동 스킬을 확인한다.
- 수집 스킬 3종은 기존 세 역할을 대체하며 등급이 높을수록 쿨다운이 짧다.

## 검증

- 확률 합 100%, 10연 희귀 보장, 100연 전설 천장 자동 검사 통과
- 하루 무료 1회 소비와 같은 날 재사용 차단 자동 검사 통과
- 기존 밸런스·장비·전투 테스트 통과
- 메인 씬 600프레임 오류 없음
- 576×896 소환 화면에서 네 탭과 모든 문구가 겹치지 않음
