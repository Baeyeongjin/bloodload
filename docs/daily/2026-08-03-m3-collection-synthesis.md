# M3 장비 수집·보유 효과·합성

> 작업일: 2026-08-03

## 완료

- 화면 전체를 덮던 투명 장비 뷰의 마우스 입력을 끄고 `장착 장비 / 보관함` 전환을 복구했다.
- 보관함을 5열 작은 카드에서 4열 큰 카드로 바꾸고 `Lv.`를 프레임 안에 고정했다.
- 전체·일반·고급·희귀·영웅·전설 등급 필터를 추가했다.
- 장비 카드를 누르면 이름, 등급, 레벨, 장착 효과, 보유 효과, 조각을 보여 주는 상세 팝업이 열린다.
- 상세 팝업에서 장착하거나 같은 장비 조각 5개를 소모해 다음 등급으로 합성한다.
- 보관한 고유 장비는 장착 여부와 무관하게 해당 스탯을 올린다. 일반부터 전설까지
  보유 효과는 각각 `+0.5% / +1% / +2% / +4% / +8%`다.
- 디버그 실행에서 뽑기 테스트가 막히지 않도록 소환 화면에 `테스트 +3000` 버튼을 추가했다.

## UI 자산 결정

기존 등급 슬롯, 장비 아이콘, 패널, 버튼만으로 등급 구분과 상세 팝업을 명확하게 만들 수 있어
PixelLab 신규 자산은 추가하지 않았다.

## 검증

- 실제 576×896 렌더에서 4열 카드, 레벨 위치, 등급 필터, 상세 팝업, 테스트 보석 버튼 확인
- 장비 보유 효과가 최대 체력에 실제 반영되는 것 확인
- 장착 탭 입력, 상세 팝업, 조각 5개 합성, 테스트 보석 자동 검사 통과
- `GearTest`, `CombatRulesTest`, `BalanceTest` 통과
- 메인 씬 600프레임 오류 없음

개발 캡처 플래그: `--tab=gear`, `--gear-mode=inventory`, `--gear-detail=first`.
