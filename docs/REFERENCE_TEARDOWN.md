## 2. 구조 판독 — 왜 저 게임은 "매일 할 게" 있는가

1. **성장 축이 12개+** (전투술·특성·스킬·숙련도·투혼·장비·룬·아케인·보물·
   유물·소울반지·칭호·호감도). 전부 종착지는 공격력·체력 몇 개다.
2. **축마다 전용 재화, 재화마다 전용 던전.** 던전은 입장권제 —
   **하루 성장량에 상한**이 있다. 스테이지가 벽이어도 "오늘 할 일"이 남는다.
3. **숫자의 규모**: 스탯 Lv.2000(상한 20,000), 영웅 Lv.536, 전투력 1.4B.
   벽이 촘촘하고, 뚫는 맛이 숫자로 크게 보인다.
4. **잠금 3종이 명시된다**: 승급 단계 · 이웃 스탯 레벨 · 콘텐츠 잠금(탭이
   보이는데 잠겨 있다).
5. **매일 루프**: 로그인 → 일일 임무판 → 던전 입장권 소진 → 방치(Pt/m·소탕권)
   → 주간/이벤트. 임무는 전부 어차피 하는 행동의 기록이다.

### 새로 확인된 장치

- **소환 천장(마일리지 상자)** — 대장간·점성소 배너마다 상자 게이지가 붙어
  있다(Lv.3 · 1,387/1,800). 뽑을수록 차고, 가득 차면 보상을 주고 상자가
  레벨업한다. 허탕 뽑기도 쌓인다는 감각 — 방치형 소환의 표준 장치.
- **시련(보스 사다리)** — 고대 유적지에서 단계 보스와 1:1. 승리 보상이
  **영구 스탯%**(공격 +575% → +913%), 다음 단계는 미궁 층이 잠근다
  ("미궁 125층 정복"). 입장권 1장. 혼자 구조에 딱 맞는 축.
- **캐릭터 정보 판** — 전투력 단일 숫자 + 최종 능력치 집계(최종 공격력·체력·
  피해 종류별 %) + 기록(총 출석일·총 플레이 시간) + 이름/외형/칭호 설정 입구.
- **방치 보상 광고 부스트** — 방치 보상 창에 "2시간 보상 0/3" 광고 버튼.
  (광고 SDK 대기 항목 — 자리만 기억)
- **마일리지 상점** — 구매 누적으로 쌓이는 재화(M)로 일일 한정 티켓·보석·
  계정당 한정 신기를 산다. 충전소(IAP)와 짝 — SDK 대기.
- **의상실(스킨 상점)** — 코스튬(픽셀 스킨)·초상을 실타래 재화로. 계정당 1회.
  우리는 skin 이 코드에만 있고 파는 곳이 없다.
- **잡화점 "일괄 획득"** — 일일 필수 구매(티켓 6종)를 버튼 하나로.
- 전당·랭킹·아레나·월드보스 — 전부 멀티. 혼자 구조라 **제외 유지**.
  단 전당의 "콘텐츠별 큰 이정표 → 보석" 과제 짜임은 우리 칭호·목표가 이미 한다.

### 제안 순서 (2026-08-18)

1. **소환 천장** — 최소 diff 로 최대 체감. 뽑기 불만(운 나쁨)을 구조로 흡수.
2. **시련** — 매일 할 일 + 영구 스탯% 축 하나. 미궁과 엇갈린 잠금까지 참고작 그대로.
3. **캐릭터 정보(전투력) 판** — "내가 얼마나 컸나"를 숫자 하나로.
4. 교환 일괄 획득 — 곁다리 QoL.
