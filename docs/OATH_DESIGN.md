# 핏빛 계약 (OathDefs) — 운빨 돌파 시스템 설계 v1

> 2026-08-18 사장님 승인: "방치형은 무조건 강해져야 넘어가니까, 운빨로
> 스테이지를 통과할 수 있게 + 과금과 자연스럽게 연결". 운빨 3겹 + 과금
> 8접점 구조로 확정. 코드 이름은 OathDefs — PactDefs(혈맹)와 충돌을 피한다.

## 0. 한 줄

벽에 막힌 군주 앞에 피의 존재들이 계약서를 내민다. **탭 한 번에 룰렛 세 번**,
좋은 계약이 뜨면 못 넘던 벽을 그 자리에서 넘는다.

## 1. 발동과 충전 (2026-08-18 사장님 수정: 상시 아이콘)

- **입구**: 전투 화면 옆줄(임무·도감 아래) **세 번째 상시 아이콘** — 언제든
  누른다. 벽 한정이 아니다. 카드가 차 있으면 아이콘이 붉게 고동친다(심장박동).
- **버프 적용**: 지금 하고 있는 전투(본편·시련·미궁·던전)에 즉시 붙는다.
  남용은 카드 경제(충전 40분·보관 3장)가 막는다.
- **충전**: 40분 1장 · 보관 3장. 방치 중 넘친 카드는 버려진다(접속 유도).
- **사용**: 탭 = 사용. 언제 쓸지(보스 직전에 아낄지)가 유저의 컨트롤.

## 2. 운빨 3겹

1. **등급 룰렛** — GachaDefs 등급·확률 그대로: 커먼50 / 언커먼30 / 레어14 /
   에픽5 / 레전1 (%).
2. **계약 룰렛** — 등급 안에서 계약 종류가 또 갈린다(아래 12종).
3. **각인 룰렛** — 부옵션 1개가 랜덤으로 박힌다(아래 6종).

**잭팟 둘**: 같은 등급 연속 2회 = **공명**(효과 1.5배, 연출 크게).
레전 위 숨은 등급 **진혈 계약 0.1%**(즉시 처형 + 카드 3장 환급).

## 3. 계약 12종 표 (초안 — 수치는 OathCheck·PaceProbe 로 확정)

효과는 전부 **이번 도전 한정**. 훅은 기존 기전 재사용(오른쪽 열).

| 등급 | 계약 | 효과 | 재사용 훅 |
|---|---|---|---|
| 커먼 | 갈증의 피 | 공격 +30% · 60초 | 가호 버프(_summon) |
| 커먼 | 밤의 보폭 | 공격 속도 +25% · 60초 | attack_interval |
| 커먼 | 여물지 않은 갑피 | 받는 피해 -25% · 60초 | 피격 식 |
| 언커먼 | 굳은 살가죽 | 받는 피해 -35% + 회복 2배 · 60초 | 피격·regen |
| 언커먼 | 붉은 갈증 | 흡혈량 +100% · 60초 | 흡혈 스탯 |
| 언커먼 | 사냥꾼의 직감 | 치명타 확률 +25%p · 60초 | crit_mult |
| 레어 | 피의 광란 | 공격 +60% + 공속 +30% · 45초 | 가호+interval |
| 레어 | 박쥐 폭풍 | 평타가 광역이 된다 · 45초 | 군림 III 광역 훅 |
| 레어 | 핏빛 장막 | 받는 피해 -60% + 초당 회복 +5% · 45초 | 피격·regen |
| 에픽 | 응혈의 시간 | 제한 시간 +20초 + 공격 +40% | _boss_time |
| 에픽 | 왕좌의 명령 | 처형 문턱 15%→35% | RULES.execute |
| 레전 | 군주의 갈증 | 보스 체력 40% 즉시 흡수 + 체력 전액 회복 | on-use 일회 |

- **계약 레벨** — 중복 획득이 그 계약의 레벨(상한 5). 레벨당 주효과 계수
  +15%p (갈증의 피 Lv5 = 공격 +90%). 카드 사용 시에만 세는 수치라 **영구
  전투력(곡선)을 오염시키지 않는다** — 과금이 사는 건 벽 돌파력이다.

## 4. 각인 6종 표 (초안)

| 각인 | 효과 |
|---|---|
| 오래 가는 피 | 지속시간 +20% |
| 짙은 피 | 주효과 +15% |
| 되돌아오는 피 | 사용 시 10% 확률로 카드 환급 |
| 서약의 가호 | 피의 서약 실패 시 건 혈액 50% 반환 |
| 공명하는 피 | 이 카드로 공명 시 1.5배 → 1.7배 |
| 천장을 두드리는 피 | 천장 카운트를 2 올린다 |

## 5. 피의 서약 (선택형 도박)

사용 전 토글. **혈액 보유량 10%를 걸면** 등급 확률이 한 단계 위로 시프트.
커먼이 뜨면 건 혈액을 잃는다. 매번의 "걸까 말까"가 컨트롤이다.

## 6. 천장 (기존 문법 복제)

- 일반 카드: **15장마다 레전 확정** (게이지 표시 — 사장님 2026-08-18: 10은
  헐거워서 15로. 황금과의 간격도 그만큼 벌어져 황금의 값이 산다)
- 황금 계약서: **5장마다 레전 확정** (전용 게이지)

## 7. 과금 8접점 — 전부 "시간 또는 운을 산다"

| # | 접점 | 내용 |
|---|---|---|
| 1 | 즉시 충전 | 보석 30 |
| 2 | 다시 굴리기 | 보석 10 · 첫 회 광고 무료 |
| 3 | 황금 계약서 | 언커먼부터 시작 + 천장 5장 |
| 4 | 계약 팩 3종 | 입문(카드5) / 도약(카드10+황금3) / 군주(황금10+각인 재굴림권5) |
| 5 | 멤버십(혈세) | 충전 40→30분 · 보관 +2 · 주간 황금 3장 |
| 6 | 계약의 서 | 미니 패스 30칸(사용 횟수로 참) — 성장 패스 판 복제 |
| 7 | 광고 3자리 | 카드 1장 x3회/일 (SDK 대기 — 자리만) |
| 8 | 한정 계약 | 시즌 패키지 (예: 만월의 계약) |

## 7.5 연출 명세 — "도박기계급" (사장님: 연출이 진짜 도박 같아야 지른다)

한 번의 탭이 **5막 연출**로 펼쳐진다. 전부 코드 연출(트윈·셰이크·틴트)이라
아트는 카드 뒷면·만월 컷신 배경 정도만 새로 뽑는다.

| 막 | 연출 |
|---|---|
| 1. 소환진 | 화면이 살짝 어두워지고 바닥에 핏빛 마법진이 회오리로 그려진다 |
| 2. 릴 | 카드가 떠올라 등급색 띠가 **릴처럼 돈다** — 레전 색 근처에서 멈칫멈칫(니어미스) 하다가 멎는다. "아깝다!"가 다음 장을 부른다 |
| 3. 개봉 | 등급색 폭발. 커먼은 짧게 톡, 레어부터 화면 흔들림 + 파티클, 에픽은 **화면 암전 + 보랏빛 낙뢰** |
| 4. 레전 | **붉은 만월 컷신** — 전투가 슬로모로 늘어지고 만월이 차오르며 카드가 뒤집힌다. 화면 전체 진동 + 핏빛 비 |
| 5. 진혈(0.1%) | 만월이 **황금으로 물들고** 화면이 깨지는 연출 + 전용 사운드 자리. 스크린샷을 찍게 만드는 그 장면 |

- 공명은 2막에서 릴이 **두 바퀴째부터 금빛 테두리**로 돌아 "예감"을 준다.
- 다시 굴리기는 2막부터 재생(1막 생략) — 굴림의 손맛이 빠르게 반복된다.

## 7.6 무과금 행운 보장 — "대박을 맛봐야 지른다" (사장님)

| 장치 | 내용 |
|---|---|
| 첫 계약 확정 | 계정 첫 카드는 **에픽 확정** — 첫 경험이 대박이어야 한다 |
| 일일 행운 | 매일 첫 카드는 등급 확률 한 단계 시프트(공짜 서약) |
| 천장 | 15장마다 레전 확정 — 무과금도 주기적으로 4~5막 연출을 본다 |
| 진혈 평등 | 진혈 0.1% 는 일반 카드에도 동일 — 무과금 잭팟 목격담이 광고다 |
| 광고 3장 | 하루 3번은 공짜로 굴린다(SDK 오면 개통) |

## 8. 가드·예외

- **주간 보스**: 흡수·처형류(군주의 갈증·왕좌의 명령·진혈)는 고정 피해로
  치환 — 누적 피해 이정표가 인플레되면 안 된다.
- **시련**: 카드 사용 가능(그게 목적) — 영구 % 가속이므로 PaceProbe 에 카드
  모델을 넣어 재측정 1회 필수.
- 상시 사용이므로 버프 지속시간이 곧 밸런스다 — 45~60초 유지, 재측정으로 확정.

## 9. 구현 지도

- `OathDefs.gd`: 계약 12종·각인 6종·확률·천장·서약 상수.
- Main: oath_cards(보유)·oath_charge(시계)·oath_pity(천장 2종)·oath_lv(도감
  레벨)·활성 버프 상태. 버프 훅은 가호(_summon_bonus) 문법 재사용.
- UI: 카드 슬롯(전투 화면) + 뒤집기 연출(등급색 글로) + 게시판 버프 표시 +
  계약 도감 소탭(도감 팝업에) + 계약의 서(패스 판 복제).
- 아트: 카드 뒷면 1 + 황금 뒷면 1 + 각인·계약 아이콘(계약은 등급색 글로로
  1차 대체 가능).
- 검사: `tests/OathCheck.gd` — 확률 합·천장 2종·서약 시프트·계약 레벨 상한·
  주간 보스 치환.
