# EXPANSION — 성장·재화·던전 확장 설계

> 2026-08-11 작성. 사장님 결정 4건 위에서 출발한다:
> **① 곱연산 축은 특성·숙련 둘 다 ② 던전은 타워형 미궁 ③ 재화는 축당 전용
> ④ 특성이 생기면 공격력 ×1.03 은 합연산으로 이관.**
>
> 참고 자료: 사장님이 플레이하는 상용 방치형 RPG 스크린샷 10장
> (`문서/카카오톡 받은 파일/방치형rpg/`). 이 문서의 구조 원칙 셋은 거기서 왔다.

---

## 0. 이 문서가 답하는 것

1. 지금 게임에 무엇이 있고 어디가 비었는가 (실측)
2. 성장을 어떤 구조로 확장하는가 (3층 구조)
3. 새 재화와 그 획득처(던전)를 어떻게 설계하는가
4. 스테이지 클리어를 향한 성장이 **점진적으로** 이어지게 하는 수학
5. 디자인(아트)이 필요한 것의 전체 목록
6. 어떤 순서로 만드는가

### 참고작에서 가져온 구조 원칙 셋

1. **모든 시스템은 같은 숫자 몇 개로 끝난다.** 화면이 15개여도 종착지는
   공격력·체력 몇 개다. 그래서 시스템 추가 = 데이터 표 + 아이콘이다.
2. **잠금이 엇갈린다.** 훈련은 던전 층이 잠그고, 던전은 훈련이 세야 오른다.
   막히면 다른 축으로 갔다가 돌아오는 왕복이 곧 "점진적 성장"이다.
3. **재화는 축마다 따로다.** 한 곳의 인플레가 다른 축을 못 무너뜨린다.

| 1층 | 무한 갈기 | **합연산** (비용 지수가 감속) | 혈액 | 구간·선행 | 스탯 훈련 (기존) |
| 2층 | 유한 선택 | **곱연산** (상한 필수) | 혈정(신규) | 던전 층·영웅 레벨 | **혈맥**(특성 트리, 신규) |
| 2층 | 유한 해금 | **기능** (숫자 아님) | 없음 (클리어 자동) | 막·보스 클리어 | **군림**(숙련, 신규) |
| 3층 | 장기 수집 | 소액 합연산 | 없음 (조건 자동) | 기록 달성 | **칭호**(신규), 도감(기존) |

### "둘 다"의 예산 분리 원칙 — 이 문서에서 가장 중요한 줄

곱연산 축을 둘(혈맥+군림) 두면 %가 양쪽에 쌓여 후반이 터질 수 있다. 그래서
**역할을 가른다: 혈맥이 숫자(%)를 전담하고, 군림은 기능 해금만 한다.**
군림에는 % 보너스를 넣지 않는다. 이 원칙이 깨지는 순간 8장의 예산표가 무효가 된다.

## 3. 신규 축 1 — 혈맥 (특성 트리)

> 이름은 임시다. 피의 군주가 핏줄을 따라 힘을 여는 그림. 사장님이 바꿔도 된다.

- **구조**: 가지 3개 × 노드 6개 = 18노드. 위에서 아래로 찍어 내려간다.
- **비용**: 노드당 혈정(6장). 티어가 오를수록 지수(×1.8)로 비싸진다.
- **잠금 두 겹** (참고작의 엇갈린 잠금):
  - 티어 게이트 — 영웅 레벨 10 / 25 / 45 / 70 / 100 / 140
  - 가지 개방 — 미궁 10층(공격) / 30층(생존) / 60층(재화)
- **데이터**: `TraitDefs.gd` 표 하나. 전투 반영은 `dps()`·`max_hp()` 에 배수 한 번.

### v1 노드 초안 (수치는 CurveSweep 재측정으로 확정)

| 가지 | 노드 (티어 순) | 완주 배수 |
|---|---|---|
| 공격 (10층) | 공격 +8% ×3 → 치명 피해 +15% ×2 → 스킬 피해 +12% ×1 | 공격 계열 ≈ ×2.2 |
| 생존 (30층) | 체력 +10% ×3 → 회복 +10% ×2 → 받는 피해 −6% ×1 | 생존 ≈ ×1.9 |
| 재화 (60층) | 혈액 +10% ×3 → 오프라인 상한 +2h ×2 → 소탕 효율 +12% ×1 | 수입 ≈ ×1.5 |

전투 곱연산 총 예산 **≈ ×2.2** (공격 가지). 8장의 예산표가 이 값을 쓴다.

## 4. 신규 축 2 — 군림 (숙련 = 기능 해금)

본편 돌파가 **자동으로** 연다. 재화도 UI 선택도 없다 — 클리어가 곧 보상.
% 는 없다 (2장의 예산 분리 원칙).

> **2026-08-11 구현 정정 — 조건을 "N막 클리어"에서 구간 이정표로 바꿨다.**
> 이 게임의 막은 50구간마다 순환한다(`act_of = major % 5`) — "1막 클리어"가
> 10구간이라 다섯 개가 51구간에 다 열려 버린다. 8장의 성장 시대 표에 맞춰
> 50 / 100 / 200 / 300 / 450 **돌파**로 잡았다(`MasteryDefs`).

| 조건(돌파) | 해금 |
|---|---|
| 본편 50 | 군림 I — 스킬 칸 6→7 |
| 본편 100 | 군림 II — 처형 문턱 15%→20% (피의 왕좌) |
| 본편 200 | 군림 III — 3연격 마무리가 광역 (fx_cleave_wave 재사용) |
| 본편 300 | 군림 IV — 방치 상한 +4시간 |
| 본편 450 | 군림 V — 미궁 소탕 2배속 |

전부 **이미 있는 코드에 걸리는 훅**이다(스킬 슬롯 상수, RULES.execute,
콤보 시스템, 오프라인 상한, 소탕 배율). 새 기계가 없다. 표시는 미궁 창의
군림 5줄과 스킬 화면의 잠긴 7번째 칸이 맡는다.

## 5. 신규 축 3 — 칭호 (장기 수집)

조건은 **이미 기록하고 있는 것**을 재활용한다: 도감 처치 수, 구간 도달,
보스 처치, 미궁 층, 스킬 승급 횟수. 새 추적 코드가 거의 없다.

- 보상 = **스탯 훈련 레벨 +N** (공짜 레벨). 합연산 축에 얹히므로 1층과 같은
  수학을 타고, 곱연산 예산을 안 건드린다.
- 참고작처럼 조건 2개 짝(예: "탐험 Lv.2 달성" + "미궁 5층 정복" → 칭호 1개).
- v1 은 12~20개면 충분하다. `TitleDefs.gd` 표 하나.

## 7. 던전 — 핏빛 미궁 (타워형)

> 이름 임시. 본편(스테이지)과 완전히 분리된 **혈정 획득처**다.

### 구조

- **층 단위 등반.** 1층 = 몹 5마리 웨이브. 5층마다 중간보스, 10층마다 보스.
  전부 **기존 로스터·보스 재활용** + 깊이에 따라 tint(어두워지고 붉어짐).
- **도전**: 현재 최고층 +1 에 도전. 클리어하면 다음 층. 실패해도 페널티 없음.
- **소탕**: 최고층 기준 시간당 혈정 (기존 오프라인 모델 재사용 — 새 기계 없음).
- **v1 상한 100층.** 층 곡선은 본편과 별도 상수 (`DungeonDefs.FLOOR_POWER`).

### 교차 잠금 (참고작의 핵심 구조)

| 방향 | 규칙 |
|---|---|
| 본편 → 미궁 | 본편 30구간 클리어 시 미궁 개방. 이후 본편 10구간마다 미궁 5층 개방 |
| 미궁 → 혈맥 | 10/30/60층이 가지 셋을 연다 (3장) |
| 미궁 → 훈련 | 20/40/80층이 스탯 상한 한 단계씩 해제 (참고작 "5단계 달성 필요" 자리) |

막히면 반대쪽을 올리고 돌아온다 — 이 왕복이 "점진적"의 실체다.

### 구현

- `DungeonDefs.gd` (층 데이터·곡선·보상), 저장은 기존 세이브에 층수 하나.
- 전투는 `Main` 의 전투 그대로 — 던전 모드 플래그 + 배경 교체 + 몹 tint.
- 탭 하나 추가 (기존 growth/gear/summon/codex 탭 구조 재사용).
- 검증: `tests/DungeonCheck.gd` — 층 곡선 단조증가, 클리어 판정이 본편과
  같은 함수(`can_clear_stage`)를 쓰는지, 소탕 수급이 6장의 표와 맞는지.

## 8. 점진 성장의 수학

### 구간대별 주력 성장원

| 구간 | 주력 | 보조 | 벽의 성격 |
|---|---|---|---|
| 1~100 | 스탯 훈련 | 스킬 뽑기 | 혈액 부족 |
| 100~300 | 장비 + 스킬 승급 | 훈련 계속 | 정수·조각 부족 |
| 300~600 | **혈맥** (미궁 등반) | 군림 해금 | 미궁 층 = 본편 진행 왕복 |
| 600~1000 | 칭호·도감 장기 수집 | 혈맥 완주 | 시간 (방치) |

### DPS 예산 (1000구간 도달 시점, 축별 곱)

```
스탯(합연산, ~150레벨)   ×6      ← 이관 후 +3.5%/레벨 기준
장비(6부위 강화)          ×4
스킬(등급·레벨)           ×3
혈맥(공격 가지 완주)      ×2.2
칭호·도감                 ×1.4
─────────────────────────────
총                       ≈ ×110
```

몹 체력 ×41(현행)에 여유 ×2.7 — 이 여유가 "제한 시간 보스"와 비용 곡선의
감속을 먹는다. 새 축이 다 들어온 뒤 몹 곡선을 1.038 → **1.045** 로 세우는 것을
후보로 두고, 반드시 `CurveSweep` 으로 재측정해서 정한다 (돈 0.55→1.10 포함 —
이미 측정된 조합: 전부 투자 벽 500→600).

### 공격력 곡선 이관 (결정 ④ 의 절차)

**혈맥 출시 커밋과 동시에 한다.** 사이가 벌어지면 그 버전은 곱연산 두 겹이다.

1. `Balance.DMG_STEP(×1.03)` 제거 → 합연산 `+3.5%/레벨` 부활 (값은 2에서 확정)
2. `CurveSweep` 에 "혈맥 완주" 정책을 추가하고, 전부 투자 벽이 500±50 을
   유지하는 합연산 기울기를 고른다
3. `BalanceTest` 의 30/60/120레벨 배수 구간·`STATS.md` 2-1 표와 4장을 갱신
4. `NoAttackProbe` 로 "안 찍으면 막힌다"가 유지되는지 확인
