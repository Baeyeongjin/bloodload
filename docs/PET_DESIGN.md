# 펫 · 도감 팝업 전환 — 설계

> 사장님 결정 2026-08-18. **아직 미구현** — 다음 작업의 출발점이다.

## 왜 이 둘이 한 묶음인가

리텐션 조사(MONETIZATION_PLAN 9-5 계열)에서 두 구멍이 나왔다.

1. **한 시간 안쪽 주기가 없다.** 방치 8시간 · 일일 24시간 · 주간 7일뿐이라
   하루 한 번 들어와 다 처리하면 그날 할 게 없다.
2. **성장이 눈에 안 보인다.** 장비를 아무리 껴도 캐릭터 그림이 그대로다.
   스킨으로 풀려다 접었다(108장 문제, MONETIZATION_PLAN 6-3).

펫이 둘 다 메운다. 그리고 펫이 하단 탭 하나를 차지하려면 **도감이 비켜야**
한다 — 도감은 팝업으로 옮긴다.

## 화면 재편

**옆줄 아이콘 (팝업, QUEST_PANEL 528x560 규격)**

| 판 | 소탭 |
|---|---|
| 임무 | 일일 · 주간 · 출석 · 은총 |
| **도감** | 몬스터 · 장비 · 스킬 · **칭호** · 연대기 |

**하단 탭**

```
성장 / 장비 / [펫] / 소환 / 던전 / 상점
```

도감이 팝업으로 가면 세로 560 을 쓴다 — 지금 반판(358)보다 넓어서 격자가
편하게 들어가고 칭호 12칸도 같이 담긴다. `_title_view`(별도 판)는 통째로
없어진다: 칭호는 성격상 "모으는 것"이고 조건도 전부 도감·구간·미궁 기록을
보므로, 같은 자리에 있어야 "무엇을 더 하면 따는지"가 보인다.

## 펫이 하는 일 — 둘 다 한다 (사장님)

**1. 자원 수집** — 짧은 시계를 만든다.

시간마다 자원을 물어오고 **상한이 있다**. 상한이 차면 멈추므로 들르는 이유가
생긴다(업계 공통 문법: 20분·5시간·2일짜리 시계를 섞는다). 우리에게 없는 건
한 시간 안쪽이므로 **30~60분 주기**가 자리다.

방치 보상(`chest_gold`)과 겹치지 않게 **다른 재화**를 물어오게 한다 —
방치는 혈액, 펫은 혈정·정수 쪽이 맞다. 같은 걸 주면 방치 상자의 값이 깎인다.

**2. 장착 시 버프** — 키우는 맛.

한 마리만 장착. 종류마다 다른 능력치(공격·체력·흡혈·소탕…)를 준다.
**성장이 눈에 보이는 게 핵심**이므로 장착한 펫은 전투 화면에서 캐릭터를
따라다녀야 한다.

## 자산

**몹 스프라이트를 재활용한다.** `assets/anim/` 에 200종 넘게 있고 walk 모션이
다 있다 — 새로 뽑을 게 없다. 펫은 캐릭터 **몸에 안 붙으므로** 스킨을 접게
만든 108장 문제가 여기엔 없다.

## 획득

소환(이미 도는 루프) 또는 도감 완성 보상. 후자를 쓰면 도감과 펫이 한 줄로
이어진다 — 도감을 채울 이유가 하나 더 생긴다.

## 손대야 할 곳

1. `TABS` 표에서 `codex` 를 `pet` 으로
2. `_build_codex` 를 팝업으로 (임무판과 같은 문법: 어둠막 + 모달 + 소탭)
3. `_build_titles` 를 도감 소탭으로 흡수, `TITLE_BTN_AT` 옆줄 버튼을 도감으로
4. `PetDefs.gd` + 수집 타이머 + 장착 상태 + 저장
5. 전투 화면에 따라다니는 스프라이트
6. `tests/PetCheck.gd` — 수집 상한, 시간 경과, 장착 버프가 실제로 붙는가

## 이미 준비된 것

- 도감 소탭 넷은 구현돼 있다(몬스터·장비·스킬·연대기, `LoreDefs.gd`).
  팝업으로 옮기면서 칭호만 더하면 된다.
- 가죽책 세트(`assets/ui/sets/tome_*`)와 `Ui.set_*` 헬퍼가 있다.
- 임무판이 같은 구조(팝업 + 소탭 넷)라 그대로 본뜨면 된다.
