## 화면 — 소환 탭(달의 제단) 문법 그대로

펫 탭을 반판에서 **전면 판(FULL_TABS)** 으로. 전용 헤더 아트 + 소탭 다섯:

```
[보유 펫]   25칸 등급색 격자 · 데려가기 · 그릇 받기
[펫 장비]   무기 25종 · 펫당 1슬롯 장착
[펫 강화]   펫 큰 그림 + 먹이 투입 + 게이지 + 단계 업 연출 (실감나게)
[펫 소환]   쇼케이스 · 확률표 · 천장 · 10연 · 소환 애니메이션 (실감나게)
[장비 소환] 같은 문법
```

각 소탭 전용 UI 세트 필요 (사장님: 탭마다 결이 달라야 한다 —
`bloodlord-per-tab-ui-sets` 규칙).

## 로스터 — 등급 5 × 5 = 25종

등급은 GachaDefs 와 같은 다섯(커먼/언커먼/레어/에픽/전설). 등급이 오를수록
물어오는 시급과 버프가 크다. 기존 6종의 "구간이 풀을 연다"는 버린다 —
**등급이 곧 희귀도**이고 풀은 처음부터 25종 전부다(천장이 상위 등급을 보장).

성장 두 축 (방치형 표준):
- **레벨** — 먹이로 올린다 (새 재화, 새 던전이 준다)
- **승급(별)** — 중복 뽑기 조각으로 올린다 (지금 조각 체계 그대로)

## 펫 장비 — 무기 25종

등급 5 × 5. 펫당 1슬롯. 아이콘 32px (기존 장비 아이콘 규격).
효과는 펫의 수집·버프를 증폭하는 쪽 (수집 +%, 버프 +%) — 영웅 장비와
겹치지 않는 축이라 파워 예산 충돌이 없다.

## 새 재화 — 먹이

- **쓰는 곳**: 펫 레벨 강화
- **주는 곳**: 새 재화 던전 (아래) + 펫 수집 소량 + 임무 예산 소폭 재분배
- 지갑 표시는 펫 탭 안에서만 (상단 지갑 칸을 안 늘린다 — 혈정·정수·인장과
  같은 급의 전용 재화 문법)

## 새 재화 던전 — 네 번째

RaidDefs 에 4번째 던전. 기존 셋: 혈액동굴(swarm)·정수성소(slay)·계약제단(endure).

- 이름 후보: **야수 우리** / 붉은 사냥터 (사장님이 고름)
- goal 은 기존 세 갈래 중 재사용 (새 규칙을 만들지 않는다)
- 배경 1장 필요 — `bg-pipeline` 스킬 규격(768×320 → 744×208)
- 던전 상세 판(RD_*)과 목록에 칸 하나 추가

## 소환권 2종 — 펫권 · 펫 장비권

TicketDefs.KINDS 에 둘 추가 (지갑 표시가 여섯 칸이 된다 — 사장님 감수 결정).
발행처 예산: 임무·출석·성장 패스·상점에서 소폭 재분배. **기존 넷의 발행량은
줄이지 않는다** — 천장 계산이 이미 그 위에 서 있다.

## 원정 v2 — 다 완성한 펫은 심부름을 간다 (2026-08-27)

원정 보상 사다리에 셋째 칸이 생겼다:

    1. 제 별 < 5성        -> 제 조각
    2. 낀 장비 < 5성       -> 장비 조각
    3. 둘 다 끝났으면      -> **보유 중 미완성 펫 가운데 제일 희귀한 놈**의 조각
    4. 로스터 전부 5성     -> 빈손 (시스템이 완성된 것)

예전엔 3번 자리가 빈손이라 **제일 공들인 펫이 그 순간 짐이 됐다.** 이제 완성한
펫이 전설 로스터의 자물쇠(중복 0.18%, 기대 9,434연)를 대신 깎는다.

규칙은 안 늘었다 — 시간은 여전히 "나올 조각의 등급"(전설 심부름 = 16시간),
새 재화·새 UI 없음. **미보유 펫 조각은 안 준다**: 그건 소환 우회다.
같은 등급이 여럿이면 표(PETS) 순서라 대상이 흔들리지 않는다.
